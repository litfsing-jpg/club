# Отчёт по реверс-инжинирингу платформы «ИИ Клуб — Первопроходцы» (club.nikexpert.ru)

Дата исследования: 17 ноября 2026 г.  
Исследуемый ресурс: `https://club.nikexpert.ru/forum/`  
Инструменты: REA (Reverse Engineer Anything), Antigravity Browser Agent, Chrome DevTools Protocol, Discourse REST API Inspector.

---

## 1. Стек и фундаментальная архитектура

- **Базовый движок**: [Discourse](https://www.discourse.org/) (современная 오픈-сорс платформа для сообществ).
- **Фронтенд**: SPA на **Ember.js** с динамической подгрузкой чанков скриптов, сервис-воркерами и WebSocket-шиной (`MessageBus`) для мгновенного обновления сообщений, статусов присутствия и уведомлений.
- **Бэкенд**: **Ruby on Rails**, реляционная БД **PostgreSQL**, кеширование и очереди **Redis**.
- **Сетевой уровень**: Nginx с HTTP/2, строгая CSP (`Content-Security-Policy`), nonce-подписи для скриптов.
- **API-модель**: Идеальный REST API — практически любой URL при добавлении `.json` или заголовка `Accept: application/json` возвращает структурированный JSON-ответ с сущностями.

## 2. Кастомный модуль доступа и монетизации (`club_access`)

Самая интересная и уникальная часть платформы — кастомный плагин **«Мой доступ в клуб»** (`club_access/account/index`, URL: `/forum/club/account`).

### Механика работы подписки и пейволла:
1. **Регистрация / Профиль**:
   - Пользователь регистрируется на форуме под своим логином и email (например, `QuietPanda64`, `sanohes@gmail.com`).
   - Ему присваивается базовый уровень `trust_level_0` / `trust_level_1`, но **без роли участника клуба** (`can_create_topic: false`, закрытые разделы скрыты).

2. **Связка с образовательной платформой / платежами**:
   - Внешний источник истины по оплате — LMS GetCourse (`edu.malovnik.ru`).
   - Реализовано 2 механизма подтверждения подписки:
     1. **OAuth / SSO / Редирект в школу GetCourse**: пользователь авторизуется в `edu.malovnik.ru`, откуда токеном подтверждается статус действующей подписки.
     2. **Подтверждение по email покупки**: если email на форуме отличается от email, с которого производилась оплата, отправляется проверочный код/ссылка.

3. **Разграничение доступа (Category & Topic Gating)**:
   - **Открыто без подписки**:
     - `Журнал` (`/forum/c/journal/24`): контентные статьи и дайджесты для прогрева аудитории.
     - `Доступ к клубу` (`/forum/c/club-access/22`): инструкция по входу и покупке.
   - **Закрыто пейволлом (требуется активная подписка клуба)**:
     - `Анонсы`
     - `Полезняки`
     - `Саммари чатов`
     - `Записи эфиров` (при попытке прямого доступа к `/t/<slug>/<id>` возвращается 404/Not Found с защитой от скачивания медиа).
     - `Моя стена` в профиле пользователя.
     - Тематические чат-каналы (`/forum/chat`).

## 3. Модули и плагины сообщества

В системе развернут комплекс плагинов:
- **Discourse Chat (`/forum/chat`)**: полноценная замена Telegram/Discord внутри платформы с каналами и тредами.
- **Reactions (`discourse-reactions`)**: расширенные реакции смайликами под постами с подсчетом статистики.
- **Topic Voting (`discourse-topic-voting`)**: голосование участников за приоритетные темы и фичи.
- **Solved (`discourse-solved`)**: механика Q&A — автор или куратор помечает правильный ответ решением.
- **Presence (`discourse-presence`)**: индикатор того, кто сейчас читает ветку или печатает ответ.
- **Templates, Checklists, Polls**: шаблоны оформления постов, интерактивные чеклисты и опросы.
